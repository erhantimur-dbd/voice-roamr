# Roamr voice agents 24/7

Global Voice agents wherever life takes you.

Self-serve Grok 2.0 voice agents for personal assistants, sales and support. Twenty-five languages, custom voices, knowledge bases, guardrails, Google Workspace, and local Twilio numbers.

Live: [roamr-mobile.vercel.app](https://roamr-mobile.vercel.app) · Site: [www.roamr.mobile](https://www.roamr.mobile)

## Product

- Voice demo on the homepage (listen + talk)
- Client console: agents, knowledge, numbers, integrations, calls, analytics, billing
- Operator desk: customers, payments, analytics, tickets
- Monthly and annual plans (Starter $49, Growth $149, Scale $399)
- Emails: hello@ / support@ / sales@ / billing@ / privacy@ roamr.mobile

## Stack

TanStack Start · React 19 · Postgres (Neon / PGLite) · Better Auth · Grok Voice · Stripe · Twilio · Resend
